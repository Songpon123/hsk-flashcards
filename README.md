# บัตรคำศัพท์ HSK 1–3 · HSK 1–3 Flashcards

บัตรคำศัพท์ภาษาจีนระดับ HSK 1–3 จำนวน 606 คำ ใช้ได้ทั้งแบบ ไทย–จีน และ English–Chinese แต่ละใบมีตัวจีน พินอิน คำแปลไทยและอังกฤษ ประโยคตัวอย่าง และที่มาของตัวอักษร คำผสมจะแยกอธิบายทีละตัว

606 HSK 1–3 words for Thai or English speakers, with pinyin, meanings, example sentences, and the origin of every character.

**เปิดใช้งาน / Open:** https://songpon123.github.io/hsk-flashcards/

## ใช้ทำอะไรได้บ้าง

- เลือกภาษา ไทย หรือ English (ทั้งคำแปลและหน้าเว็บเปลี่ยนตาม)
- เลือกระดับ HSK 1, 2, 3 หรือทั้งหมด
- ดูเฉลยใต้คำได้ทันทีโดยไม่ต้องพลิกบัตร เลือกได้ว่าจะให้ด้านหน้าเป็นภาษาจีน หรือเป็นคำแปล
- ส่วน “ที่มาและความหมาย” บอกความหมายตามตัวของคำผสม และอธิบายตัวอักษรทีละตัวว่าสร้างจากอะไร
  (ส่วนความหมาย + ส่วนเสียง, อักษรรวมความหมาย หรืออักษรภาพ)
- ซ่อนหรือแสดงพินอินที่ด้านหน้าบัตร
- กด “ยังไม่แม่น” / “จำได้แล้ว” แล้วกรองให้เหลือเฉพาะคำที่ยังไม่แม่น (บันทึกไว้ในเบราว์เซอร์ของแต่ละเครื่อง)
- สุ่มลำดับบัตร และค้นหาด้วยตัวจีน คำไทย คำอังกฤษ หรือพินอินแบบไม่ใส่วรรณยุกต์ (เช่น `xuexi`)
- ฟังเสียงคำและประโยค เมื่อเครื่องมีเสียงอ่านภาษาจีน
- คีย์ลัด: `Space` ดูเฉลย, `←` `→` เปลี่ยนบัตร, `1` ยังไม่แม่น, `2` จำได้แล้ว และบนมือถือปัดซ้ายขวาเพื่อเปลี่ยนบัตร

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/hsk*.txt` | คำศัพท์ บรรทัดละคำ: `ตัวจีน\|พินอิน\|คำแปลไทย\|ประโยค\|พินอินประโยค\|คำแปลประโยค` |
| `src/extra/hsk*.txt` | ภาษาอังกฤษและความหมายตามตัว: `ตัวจีน\|พินอิน\|English\|English sentence\|ความหมายตามตัว\|literal meaning` |
| `src/chars/c*.txt` | ความหมายภาษาไทยของตัวอักษรแต่ละตัว และคำอธิบายที่มาภาษาไทย |
| `src/chars/meaning-parts.txt` | ความหมายภาษาไทยของส่วนประกอบที่บอกความหมาย |
| `src/chars/makemeahanzi-subset.jsonl` | โครงสร้างตัวอักษรจาก Make Me a Hanzi (ดู `DATA_LICENSE.md`) |
| `index.html`, `app.js` | หน้าตาและการทำงานของบัตรคำ |
| `build.py` | รวมข้อมูลและสร้างหน้าเว็บ |
| `docs/` | หน้าเว็บที่ GitHub Pages ใช้แสดงผล |
| `hsk-flashcards-offline.html` | ไฟล์เดียวจบ เปิดในเครื่องได้โดยไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นฟอนต์) |

## แก้ไขคำศัพท์

1. แก้ไฟล์ใน `src/`
2. รัน `python3 build.py` ในโฟลเดอร์นี้ (สคริปต์จะแจ้งถ้าข้อมูลขาดหรือไม่ครบ)
3. commit แล้ว push ขึ้น GitHub หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที
