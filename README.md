# บัตรคำศัพท์ HSK 1–3

บัตรคำศัพท์ภาษาจีนระดับ HSK 1–3 จำนวน 606 คำ แต่ละใบมีตัวจีน พินอิน คำแปลไทย และประโยคตัวอย่างพร้อมพินอินและคำแปล

**เปิดใช้งาน:** https://songpon123.github.io/hsk-flashcards/

## ใช้ทำอะไรได้บ้าง

- เลือกระดับ HSK 1, 2, 3 หรือทั้งหมด
- พลิกบัตรได้ทั้งแบบ จีน → ไทย และ ไทย → จีน
- ซ่อนหรือแสดงพินอินที่ด้านหน้าบัตร
- กด “ยังไม่แม่น” / “จำได้แล้ว” แล้วกรองให้เหลือเฉพาะคำที่ยังไม่แม่น (บันทึกไว้ในเบราว์เซอร์ของแต่ละเครื่อง)
- สุ่มลำดับบัตร และค้นหาด้วยตัวจีน คำไทย หรือพินอินแบบไม่ใส่วรรณยุกต์ (เช่น `xuexi`)
- ฟังเสียงคำและประโยค เมื่อเครื่องมีเสียงอ่านภาษาจีน
- คีย์ลัด: `Space` พลิก, `←` `→` เปลี่ยนบัตร, `1` ยังไม่แม่น, `2` จำได้แล้ว และบนมือถือปัดซ้ายขวาเพื่อเปลี่ยนบัตร

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/hsk1*.txt`, `src/hsk2*.txt`, `src/hsk3*.txt` | ข้อมูลคำศัพท์ บรรทัดละคำ: `ตัวจีน\|พินอิน\|คำแปล\|ประโยค\|พินอินประโยค\|คำแปลประโยค` |
| `index.html`, `app.js` | หน้าตาและการทำงานของบัตรคำ |
| `build.py` | รวมข้อมูลและสร้างหน้าเว็บ |
| `docs/` | หน้าเว็บที่ GitHub Pages ใช้แสดงผล |
| `hsk-flashcards-offline.html` | ไฟล์เดียวจบ เปิดในเครื่องได้โดยไม่ต้องต่ออินเทอร์เน็ต (ยกเว้นฟอนต์) |

## แก้ไขคำศัพท์

1. แก้ไฟล์ใน `src/`
2. รัน `python3 build.py` ในโฟลเดอร์นี้
3. commit แล้ว push ขึ้น GitHub หน้าเว็บจะอัปเดตเองภายในไม่กี่นาที

## หมายเหตุ

รายการคำศัพท์อิงตาม HSK มาตรฐานเดิม (HSK 2.0) ระดับ 1–3 ประโยคตัวอย่างและคำแปลไทยเรียบเรียงขึ้นใหม่สำหรับชุดนี้ หากพบจุดที่ควรแก้ แจ้งผ่าน Issues ได้เลย
